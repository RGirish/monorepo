# Week 13 — Mar 30

## AI Learning: Feature Engineering

Explored feature engineering — the process of transforming raw data into representations that ML models can effectively exploit. Covered the core trial-and-error workflow, how feature types vary by data modality (tabular, text, audio, images, video), and the key shift from manual feature design to **representation learning** in deep learning systems, where neural networks learn features directly from raw data during training instead of relying on human-designed rules.

Dug into how feature learning works mechanistically in deep networks: each layer progressively extracts richer, more abstract representations — feature richness compounds layer by layer. Given a large enough dataset, a deep network can automatically discover which features matter, removing the need to know in advance what to extract. This scalability advantage over hand-engineering is especially pronounced as dataset diversity and model generalization requirements grow.

Also explored how feature engineering manifests in the LLM/GenAI era: context engineering in RAG systems (chunking and metadata tagging as a form of feature design), numerical translation for tabular LLM inputs, prompt precision as a way to reduce ambiguity, hybrid pipelines that combine XGBoost-style feature-heavy models with GenAI, and the growing use of LLMs themselves to brainstorm and generate new features for other models.
