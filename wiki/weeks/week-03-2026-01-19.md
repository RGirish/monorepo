# Week 3 — Jan 19

## AI Learning: Strands Agents + Ollama

Strands Agents is a Python framework for building AI agents that handles the orchestration loop, tool calling, and conversation management. It was explored alongside Ollama, a tool for running large language models locally, which enabled building agents that don't depend on external API calls. The combination provides a self-contained, privacy-friendly stack for agent development.

→ [Strands Agents](../tools/strands-agents.md)
→ [Ollama](../tools/ollama.md)

## Build: Jarvis Chatbot

Built a personal AI chatbot named Jarvis using the Strands Agents framework with Ollama for local model inference. Jarvis serves as a personal assistant that can hold conversations and call tools, all running locally without requiring cloud API keys. This was the starting point for a multi-week project — Jarvis was extended in weeks 4 and 5 with MCP tool access and an A2A protocol server.
