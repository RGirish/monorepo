# Week 4 — Jan 26

## AI Learning: More Strands Agents + AG-UI Protocol

This week went deeper into Strands Agents alongside exploring the AG-UI (Agent-User Interaction) protocol. AG-UI is a standardized protocol that defines how AI agents stream events and state updates to frontend user interfaces — solving the problem of inconsistent streaming APIs across different agent frameworks. It complements A2A (agent-to-agent) by handling the human-facing side of the agent communication stack.

## Build 2: Two-Phase Commit

Implemented the 2-phase commit (2PC) distributed consensus protocol in Python. 2PC coordinates a transaction across multiple participant nodes in two phases: a prepare phase where all nodes vote on whether they can commit, and a commit phase where the coordinator instructs all nodes to commit or abort based on the votes. It's a foundational building block for distributed database transactions.
