# Week 2 — Jan 12

## AI Learning: Claude Code

Claude Code is Anthropic's official CLI tool for AI-assisted coding that runs directly in the terminal. It can read and write files, execute shell commands, and interact with MCP servers, making it well-suited for agentic coding workflows that span multiple files and tools. It differs from IDE-embedded AI tools by treating the terminal as its primary interface, which gives it broader system access and composability with other CLI tools.

→ [Claude Code](../tools/claude-code.md)

## Build: TODO MCP Server

Built an MCP (Model Context Protocol) server that exposes TODO management as a set of AI-callable tools. The server allows MCP-compatible clients like Claude Code to create, list, complete, and delete todo items through the standardized tool interface. This was also the foundation for a later integration where Jarvis (built in week 3) was connected to consume this server.
