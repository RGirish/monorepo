# Week 9 — Mar 02

## AI Learning: OpenClaw — Sandboxed AI Coding

OpenClaw is an AI coding tool that runs inside Docker sandboxes to provide secure, isolated code execution. The key insight is that AI agents writing and running code need sandboxing to prevent unintended side effects on the host system. The Docker blog post covering OpenClaw explains the architecture for running AI code execution safely: each agent session gets an isolated container with controlled network and filesystem access.

## Build: Collaborative Text Editor with CRDT

Built a collaborative text editor using CRDTs (Conflict-free Replicated Data Types), which allow multiple clients to make concurrent edits to a shared document without coordination or locking. CRDTs achieve this by defining merge operations that are commutative, associative, and idempotent — so the final state is always consistent regardless of the order operations are received. The build demonstrates why CRDTs are preferred over operational transformation for distributed collaboration.
