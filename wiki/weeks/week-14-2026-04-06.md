## AI Topic: Multi-turn Reinforcement Learning and Evaluation

Covered the full arc of RL from first principles through its application to LLMs:

- **Reward function design** — reward hacking, sparse rewards, discount factor γ, multi-objective rewards, and Goodhart's Law
- **Value function and credit assignment** — how a simple terminal reward + learned value function beats a complex shaped reward; the chess analogy

- **MTRL system components** — base model, conversation simulator, reward model, credit assignment strategy, PPO, KL penalty/reference model, evaluation harness

## Build: Asymmetric Encryption

Python implementation of in-memory asymmetric encryption with signature verification, simulating secure two-party communication between Alice and Bob.

Key concepts implemented:
- **RSA key pair generation** — 2048-bit keys, public exponent 65537
- **OAEP encryption/decryption** — Optimal Asymmetric Encryption Padding with SHA-256; randomised padding that detects corruption and defeats malleability attacks
- **PSS signing/verification** — Probabilistic Signature Scheme; signs over plaintext hash with sender's private key, verified with public key
- **Hybrid encryption note** — RSA only suitable for small payloads; real systems encrypt an AES key with RSA, then use AES for bulk data (as in TLS)
- **Four attack scenarios** — corrupted ciphertext (OAEP detects), swapped message with reused signature (sig mismatch), wrong decryption key, mismatched signature over different plaintext
