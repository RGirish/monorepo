# Week 11 — Mar 16

## AI Learning: Language Modeling — Neural Network Framework (makemore continued)

Continued Karpathy's makemore series, this time reformulating the same bigram model using a single-layer neural network trained via gradient descent. The key insight is that the count matrix from week 10 is exactly equivalent to a one-hot encoded input multiplied by a weight matrix — so the neural net learns the same probabilities, but through backpropagation rather than counting. This establishes the neural network training loop pattern: forward pass, loss computation, backward pass, weight update.

## Build: Bigram Model in Neural Network Framework

Reformulated the week 10 bigram model as a single-layer neural network using PyTorch in a Jupyter notebook (makemore.ipynb). The network takes one-hot encoded characters as input, passes them through a linear layer, applies softmax to produce probabilities, and trains using cross-entropy loss via gradient descent. This bridges the gap between classical statistics and modern deep learning, showing they converge to the same solution from different directions.
