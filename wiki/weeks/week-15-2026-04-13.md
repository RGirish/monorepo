# Week 15 — Context Engineering + Signal Protocol Chat

## AI Topic: Context Engineering

Covered Anthropic's framework for thinking about context as a finite, managed resource — the natural evolution of prompt engineering for agentic systems.

Key concepts:

- **Context rot** — LLM performance degrades as context grows due to the transformer's n² attention calculation; larger contexts strain the model's "attention budget"
- **Anatomy of good context** — system prompts (specific but flexible), tools (non-overlapping, unambiguous), examples (curated and canonical, not exhaustive)
- **Just-in-time retrieval** — load context dynamically via tools rather than pre-loading everything; progressive disclosure over exploration
- **Long-horizon techniques** — compaction (summarize and reinitialize), structured note-taking (persist outside context window), sub-agent architectures (clean context per specialist agent)
- **Guiding principle** — "find the smallest set of high-signal tokens that maximize the likelihood of your desired outcome"

The distinction from prompt engineering: prompt engineering is about instruction quality for single tasks; context engineering is about managing what the model is aware of across multi-turn agent sessions.

## Build: Signal Protocol Chat

A local, single-device simulation of a 2-person end-to-end encrypted chat built directly on Signal's real `libsignal-android` library (Android/Kotlin, Jetpack Compose) — not a reimplementation, the actual production cryptography. Alice and Bob each get an isolated identity and session store; the only shared state is a simulated wire carrying ciphertext.

Implemented end-to-end: identity/pre-key generation (including a Kyber post-quantum pre-key), **PQXDH** session establishment (the post-quantum-hardened successor to X3DH), and the **Double Ratchet** for per-message encryption — with the UI enforcing the real session asymmetry (the responder can't send until they've decrypted a first message from the initiator). Also covered: the mechanics behind **forward secrecy** and **post-compromise security**, why the signed/Kyber pre-keys need a signature but the one-time pre-key doesn't, and the protocol's history from OTR through TextSecure/Axolotl to WhatsApp's 2016 rollout.

Real network transport between separate devices, persistent storage, and Play Store deployment were explicitly deferred — tracked in `wiki/backlog.md`.
