# Week 5 — Feb 02

## AI Learning: A2A Protocol

A2A (Agent-to-Agent) is an open protocol for enabling AI agents to communicate with, discover, and delegate tasks to each other. It defines a standard lifecycle for tasks (submitted, working, completed, failed), a message-passing format, and an agent discovery mechanism via "Agent Cards." A2A is designed to be framework-agnostic so that agents built with different tools can interoperate — complementing MCP (which handles tool/resource access) with a higher-level agent coordination layer.

→ [A2A Protocol](../tools/a2a-protocol.md)

## Build: Jarvis A2A Server

Added an A2A protocol server to the Jarvis chatbot, allowing other agents to discover Jarvis and delegate tasks to it over the A2A protocol. This transformed Jarvis from a standalone chatbot into a participant in a multi-agent network. Combined with the MCP integration from week 4, Jarvis can now both consume tools (via MCP) and be consumed by other agents (via A2A).
