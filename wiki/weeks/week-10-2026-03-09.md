# Week 10 — Mar 09

## AI Learning: Language Modeling — Bigram Model (makemore series)

Started Andrej Karpathy's "makemore" series on building language models from scratch. The first video covers building a character-level bigram model: constructing a count matrix of all character pair frequencies from a training corpus, normalizing rows into probability distributions using softmax, and sampling from those distributions to generate new sequences. The series also introduces cross-entropy loss as the metric for evaluating how well the model's predicted probabilities match the training data.

## Build: Bigram Language Model

Built a bigram character-level language model trained on a names dataset (makemore). The count-based implementation records how often each character follows every other character, converts the counts to probabilities, and generates new names by sampling character by character from the learned distributions. This establishes the baseline that week 11's neural network reformulation is measured against.
