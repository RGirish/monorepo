# Week 8 — Feb 23

## AI Learning: Ralph Autonomous Agent System

Ralph is an autonomous agentic coding workflow system created by Geoffrey Huntley that structures how AI agents take on and complete development tasks. It defines a disciplined process for breaking down work, maintaining context across steps, and producing verifiable outputs — addressing the challenge of keeping long-horizon AI coding tasks on track. Ralph treats the agent's work as a structured project rather than an open-ended conversation.

## Build: TCP Three-Way Handshake

Implemented a simulation of the TCP three-way handshake — the connection establishment protocol used before any data transfer in TCP. The simulation covers all three steps: SYN (client initiates), SYN-ACK (server acknowledges and responds), and ACK (client confirms). This is a foundational networking concept that demonstrates how TCP provides reliable, ordered communication on top of an unreliable network layer.
