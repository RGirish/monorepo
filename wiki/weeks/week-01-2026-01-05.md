# Week 1 — Jan 05

## AI Learning: Beads — Coding Agent Memory System

Beads is a coding agent memory system created by Steve Yegge that enables AI coding agents to maintain persistent memory across sessions. The core idea is that "beads" are discrete, structured memory units that an agent can store, retrieve, and reason over — solving the context-window amnesia problem that plagues long-running agent workflows. The system is designed to work alongside existing coding agents rather than replace them.

## Build: Bloom Filter

A bloom filter is a probabilistic data structure for testing set membership that is highly space-efficient. The implementation uses multiple hash functions to map elements to bit positions in a bit array, supporting fast insertions and lookups. False positives are possible (it may say an element is in the set when it isn't), but false negatives are impossible — if it says an element is absent, it definitely is.
