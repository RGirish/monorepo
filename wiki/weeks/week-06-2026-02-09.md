# Week 6 — Feb 09

## AI Learning: Agent Client Protocol (ACP)

ACP (Agent Client Protocol) standardizes how client applications — browsers, mobile apps, desktop tools — interact with AI agents. While A2A handles agent-to-agent communication and MCP handles tool/resource access, ACP fills the gap at the client boundary: how does a human-facing app send requests to an agent and receive structured responses? The protocol defines request/response formats, streaming conventions, and error handling for this client-facing interface.

## Build: Symmetric Encryption

Implemented symmetric encryption from scratch, covering the core algorithms and concepts: shared secret keys, block ciphers, padding schemes, and modes of operation (ECB, CBC, CTR). The build reinforced the fundamental distinction between symmetric encryption (same key for encrypt and decrypt) and asymmetric encryption, and why modes of operation matter for security beyond the base cipher.
