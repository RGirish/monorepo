## Build: LLM Music Producer

Two experimental pipelines that use an LLM as audio composer, packaged as [agentskills.io](https://agentskills.io) skills. Both run end-to-end inside an agent context window with no external model calls.

**Base95 approach:** MP3 frames are parsed, headers stripped (they're deterministic, so the code generates them), and audio payloads encoded as Base95 printable ASCII. The LLM studies example payloads and synthesizes new ones; the code reconstructs a valid MP3. Output is noise-like — the LLM is pattern-matching on compressed spectral data without musical semantics.

**MIDI-as-text approach:** MP3 files are transcribed to note events using Spotify's `basic-pitch` library. The LLM reads the MIDI-as-text (one note per line: time, pitch, velocity, duration), composes a new piece in the same register and style, and writes it back as text. The code synthesizes audio via fluidsynth and ffmpeg.
