## Build: LLM Music Producer (in progress)

An experimental pipeline that encodes MP3 audio files as Base95 text, passes them to an LLM to synthesize new audio payloads, then reconstructs a valid MP3. The key insight: MP3 frame headers are deterministic for a fixed bitrate/samplerate, so the code handles them — the LLM only generates the audio payload bytes (Huffman-coded spectral data), giving it the best possible chance of learning patterns from the input audio.

Pipeline: MP3 files → parse frames → strip headers → encode payloads as Base95 → LLM synthesis → decode payloads → prepend headers → valid MP3.

Packaged as an [agentskills.io](https://agentskills.io) skill so any compatible agent can run the full pipeline end-to-end.
